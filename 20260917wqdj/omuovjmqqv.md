# 齐鲁医院戒烟门诊完成首例多学科会诊

> 更新时间：2026-09-17 (UTC+8)

近日，齐鲁医院戒烟门诊完成首例多学科会诊。此次会诊标志着戒烟门诊服务模式全面升级，从健康科普劝导转向专业化评估、个体化指导、多学科协作与全程化管理的系统干预体系。

50 余岁的 “资深烟民” 傅先生，因多次戒烟失败且患有冠心病、高血压等基础疾病，寻求专业医疗帮助。门诊启动多学科会诊（MDT）模式，呼吸科李昊副主任医师、针灸科岳公雷副主任医师、心理科刘道力医师、戒烟门诊赵丽霞主任药师共同接诊。专家团队仔细询问了傅先生的吸烟史、既往健康状况，并通过专业的烟草依赖程度量表评估、心理行为评估及中医体质辨识，系统剖析了其屡次戒烟不成功的原因与身心状况。结合傅先生患有冠心病、高血压等基础疾病的情况，团队为他量身定制了一套涵盖基础疾病排查、药物干预、心理疏导、针灸调理与行为管理的整合式戒烟方案，旨在平稳、安全、有效地助其实现戒烟目标。

随后就诊的30 多岁 “新晋奶爸”，为给家人营造无烟环境，主动选择药物辅助戒烟。医师结合其特点提供个性化行为指导，药师则详细讲解用药相关知识，保障其科学安全用药。

此次多学科会诊标志着戒烟门诊完成从健康咨询到规范诊疗的升级。未来，齐鲁医院戒烟门诊将推广“评估—干预—随访” 一体化服务，探索线上线下结合新模式，提供更优质的戒烟支持，持续为戒烟者保驾护航，助力大众迈向无烟健康生活。
